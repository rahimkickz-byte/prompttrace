## Public PromptTrace app

[Open PromptTrace](https://prompttrace-4bgmed8n.manus.space/) · [What's new](https://prompttrace-4bgmed8n.manus.space/whats-new) · [Privacy and data controls](https://prompttrace-4bgmed8n.manus.space/privacy)

PromptTrace turns image, audio, and video references into inferred creative prompt specifications. Results are suggestions, not proof of the exact original prompt or generation settings.

The site is published with public access. A public discovery and What's New update has been submitted for publication. Gemini analysis is currently paused until its connection is configured; Stripe checkout remains sandbox mode, not a verified paid production launch. Account history and payments remain private.

This repository currently contains documentation and related files, not the deployed app's source. The app is maintained in its original Manus website project.
